# Tarea 4 — Arquitectura de Computadores

Este repositorio contiene tres programas en lenguaje ensamblador MASM/TASM.

## Programas

1. **Aritmética hexadecimal** — `programa1-aritmetica/aritmetica.asm` lee dos
   bytes hexadecimales y realiza suma o resta, mostrando el resultado y el
   acarreo o préstamo.
2. **Máscaras lógicas** — `programa2-mascaras/mascaras.asm` aplica AND, OR o
   XOR a un byte de entrada y muestra el resultado en binario de 8 bits.
3. **Contador hexadecimal** — `programa3-contador/contador.asm` recorre y
   muestra en orden los dígitos hexadecimales desde `0` hasta `F`.
